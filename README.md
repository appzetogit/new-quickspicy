# Quick Spicy

Food delivery platform: customer web app, restaurant app, rider app and admin
panel (`Frontend/`, React + Vite), backed by a Node API on PostgreSQL
(`Backend/`, Express + Prisma).

- Web: https://new.quickspicy.in
- API: https://api-new.quickspicy.in

Brand assets (logo set, icons, link-preview image) are in
`Frontend/public/brand/`. Orange `#EB590E` is the brand colour; the theme
tokens live in `Frontend/src/shared/styles/global.css`.

Deploying: see `deploy/DEPLOY.md`. Read its "Before every deploy" check first.
